# Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a dataset using Python.

The main goal is to understand the structure of the data, identify patterns, detect missing values and outliers, and generate useful insights through data visualization.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Analysis Performed

- Dataset inspection
- Data cleaning
- Missing value analysis
- Duplicate value detection
- Descriptive statistics
- Univariate analysis
- Bivariate analysis
- Outlier detection
- Correlation analysis
- Data visualization
- Insight generation

## 📊 Visualizations

The project includes different visualizations such as:

- Histograms
- Box plots
- Count plots
- Scatter plots
- Correlation heatmap

## 📁 Project File

`Project(EDA).ipynb` - Complete EDA analysis performed using Jupyter Notebook.

## 🎯 Key Learning

This project helped me understand how to explore a real-world dataset, identify data quality issues, visualize important patterns, and extract meaningful insights using Python.
